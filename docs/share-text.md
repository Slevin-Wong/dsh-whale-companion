# 分享文案

给朋友、群里或社交平台发链接时可以直接用下面任意一段。

## 一句话

> 给 DeepSeek Harness 做了个鲸鱼娘挂件：右下角常驻，实时显示余额，16 张表情能自动换也能点着换。

## 微信群 / QQ 群

> 【自制 DSH 插件】鲸鱼娘余额伙伴
> 右下角常驻一只鲸鱼娘，实时显示 DeepSeek 账户余额（充值余额 + 赠送额度分开显示），30 秒自动刷新，点一下金额就立刻更新。
> 内置 16 张表情：左键换一张、Shift+左键随机换，也能设成自动轮换或手动。
> 装法：下载 Release 里的 zip → 解压 → Harness 里「插件 → 添加插件」粘贴文件夹路径，或者直接把路径丢给 Agent 让它装。需要已登录的 DeepSeek 账户。
> 代码 MIT，图是非商用同人，来自「蓝色大肥鱼」表情包合集。
